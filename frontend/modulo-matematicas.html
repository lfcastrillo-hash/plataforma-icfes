🔢 Pensamiento Numérico y Sistemas Numéricos

✓ Completado

Números naturales, enteros, racionales, irracionales, potencias, raíces, logaritmos, proporciones y valor absoluto.

1.1 Conjuntos Numéricos

Los números se organizan en conjuntos anidados: cada uno contiene al anterior.

ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ
Naturales: {0, 1, 2, 3, …}
Enteros: {…, −2, −1, 0, 1, 2, …}
Racionales: todo número p/q con q ≠ 0 (fracciones, decimales finitos y periódicos)
Irracionales: no expresables como fracción → √2, π, e, √3
Reales: ℚ ∪ Irracionales
💡 Todo número racional tiene una expresión decimal que termina (0,25) o se repite periódicamente (0,333…). Si el decimal no se repite ni termina, el número es irracional.

1.2 Operaciones con Fracciones

Suma/Resta: a/b ± c/d = (ad ± bc) / bd
Multiplicación: (a/b)×(c/d) = ac/bd
División: (a/b)÷(c/d) = (a/b)×(d/c) = ad/bc
Simplificación: dividir numerador y denominador por su MCD
2/3 + 5/4 = (8 + 15)/12 = 23/12
(3/5) ÷ (9/10) = (3/5)×(10/9) = 30/45 = 2/3

1.3 Potencias y sus Leyes

aⁿ × aᵐ = a^(n+m) (misma base → suma exponentes)
aⁿ / aᵐ = a^(n−m) (misma base → resta exponentes)
(aⁿ)ᵐ = a^(n×m) (potencia de potencia → multiplica)
(ab)ⁿ = aⁿ × bⁿ (potencia de producto)
a⁻ⁿ = 1/aⁿ (exponente negativo → inverso)
a⁰ = 1 (a ≠ 0)
(2³)² / 2⁴ = 2⁶/2⁴ = 2² = 4
(3x²y)³ = 27x⁶y³

1.4 Raíces y Radicales

ⁿ√a = a^(1/n)
√(a×b) = √a × √b (producto de radicales)
√(a/b) = √a / √b (cociente de radicales)
√(aⁿ) = a^(n/2)
Racionalizar: multiply por √b/√b para eliminar raíz en denominador
√72 = √(36×2) = 6√2
√3/√5 = √3·√5/5 = √15/5 (racionalizado)
³√54 = ³√(27×2) = 3·³√2

1.5 Logaritmos

El logaritmo responde: ¿a qué potencia debo elevar la base para obtener el argumento?

log_b(x) = n ⟺ bⁿ = x
log(x×y) = log x + log y (producto → suma)
log(x/y) = log x − log y (cociente → resta)
log(xⁿ) = n·log x (potencia → multiplica)
log_b(b) = 1 (log de la base = 1)
log_b(1) = 0 (log de 1 = 0)
Cambio de base: log_b(x) = ln(x)/ln(b)
log₂(32) = log₂(2⁵) = 5
log(100) = log(10²) = 2
log(6) = log(2×3) = log 2 + log 3 ≈ 0,301 + 0,477 = 0,778

1.6 Valor Absoluto

|x| = x si x ≥ 0
|x| = −x si x < 0
|a − b| = distancia entre a y b en la recta numérica
|x| < k ⟺ −k < x < k
|x| > k ⟺ x > k o x < −k
|2x − 3| = 7 → 2x−3 = 7 o 2x−3 = −7 → x = 5 o x = −2
|x + 1| < 4 → −4 < x+1 < 4 → −5 < x < 3

1.7 Razones, Proporciones y Regla de Tres

Razón: a:b = a/b
Proporción: a/b = c/d ⟹ ad = bc (propiedad cruzada)
Regla de tres simple directa: a→b, c→x : x = bc/a
Regla de tres simple inversa: a→b, c→x : x = ab/c
Regla de tres compuesta: combina varias magnitudes
Directa: 4 obreros → 12 días; 6 obreros → x días (inversa)
x = 4×12/6 = 8 días
Proporciones: Si a/b = c/d, entonces (a+b)/b = (c+d)/d (propiedad componendo)

1.8 Porcentajes y Variaciones

% de X = X × porcentaje / 100
Aumento: Nuevo = Original × (1 + p/100)
Descuento: Nuevo = Original × (1 − p/100)
Variación %: ((Nuevo − Original) / Original) × 100
Interés simple: I = C × r × t
Interés compuesto: M = C × (1 + r)ᵗ
Aumento del 15% sobre $80.000: 80.000 × 1,15 = $92.000
Interés compuesto: $1.000 al 10% anual, 3 años → 1.000 × 1,1³ = $1.331

1.9 Divisibilidad, MCD y MCM

MCD(a,b): mayor divisor común → algoritmo de Euclides
MCM(a,b) = (a × b) / MCD(a,b)
Criterios de divisibilidad:
Entre 2: último dígito par
Entre 3: suma de dígitos divisible entre 3
Entre 4: últimos dos dígitos divisibles entre 4
Entre 5: termina en 0 o 5
Entre 9: suma de dígitos divisible entre 9
MCD(48, 18): 48 = 2·18 + 12; 18 = 1·12 + 6; 12 = 2·6 → MCD = 6
MCM(48, 18) = (48×18)/6 = 144

Ejercicios tipo ICFES

8 preguntas
1. ¿Cuál de los siguientes números es irracional?
✅ √7 ≈ 2,6457… es irracional porque 7 no es cuadrado perfecto. √9 = 3 (entero), 0,666… = 2/3 (racional), −5/3 es fracción.
2. Simplifica: (3⁴ × 3⁻²) / 3³
✅ 3^(4−2−3) = 3^(−1) = 1/3
3. Si log₂(x) = 5, ¿cuánto vale x?
✅ log₂(x) = 5 ⟺ 2⁵ = x → x = 32
4. Resuelve: |3x − 6| = 9
✅ 3x−6 = 9 → x = 5; o 3x−6 = −9 → x = −1. Ambas soluciones: x = 5 y x = −1
5. Un capital de $500.000 se invierte al 8% de interés compuesto anual. ¿Cuánto tendrá después de 2 años?
✅ M = 500.000 × (1,08)² = 500.000 × 1,1664 = $583.200
6. Simplifica completamente: √(48x⁴y²)
✅ √48 = 4√3; √(x⁴) = x²; √(y²) = |y|. Resultado: 4x²|y|√3
7. Si 8 impresoras imprimen 600 páginas en 5 horas, ¿cuántas páginas imprimen 6 impresoras en 3 horas?
✅ Regla de tres compuesta: x = 600 × (6/8) × (3/5) = 600 × 0,75 × 0,6 = 270 páginas
8. Usa log 2 ≈ 0,301 y log 3 ≈ 0,477. ¿Cuánto es log(72)?
✅ 72 = 8×9 = 2³×3². log 72 = 3 log 2 + 2 log 3 = 3(0,301)+2(0,477) = 0,903+0,954 = 1,857

🔣 Álgebra

✓ Completado

Expresiones algebraicas, factorización, ecuaciones de 1.° y 2.° grado, sistemas de ecuaciones, inecuaciones y variación.

2.1 Productos Notables

(a+b)² = a² + 2ab + b²
(a−b)² = a² − 2ab + b²
(a+b)(a−b) = a² − b² (diferencia de cuadrados)
(a+b)³ = a³ + 3a²b + 3ab² + b³
(a−b)³ = a³ − 3a²b + 3ab² − b³
(a+b+c)² = a²+b²+c²+2ab+2ac+2bc
(3x+2)² = 9x²+12x+4
(5x−3)(5x+3) = 25x²−9

2.2 Factorización

Factor común: ax+ay = a(x+y)
Diferencia cuadrados: a²−b² = (a−b)(a+b)
Trinomio cuadrado perfecto: a²±2ab+b² = (a±b)²
Trinomio general: x²+bx+c → busca m,n: m+n=b, mn=c
Suma/Diferencia de cubos: a³+b³ = (a+b)(a²−ab+b²)
a³−b³ = (a−b)(a²+ab+b²)
x²−5x+6 = (x−2)(x−3) porque −2+(−3)=−5 y (−2)(−3)=6
8x³−27 = (2x−3)(4x²+6x+9)

2.3 Ecuaciones de Primer Grado

ax + b = c → x = (c−b)/a
Con fracciones: multiplicar toda la ecuación por el MCM de denominadores
Con paréntesis: distribuir primero, luego agrupar términos
3(x−2) = 2x+7 → 3x−6 = 2x+7 → x = 13
x/3 + x/4 = 7 → MCM=12: 4x+3x = 84 → 7x=84 → x=12

2.4 Ecuaciones de Segundo Grado

ax²+bx+c = 0
Fórmula general: x = (−b ± √(b²−4ac)) / 2a
Discriminante Δ = b²−4ac:
Δ > 0 → dos raíces reales distintas
Δ = 0 → raíz doble: x = −b/2a
Δ < 0 → no hay raíces reales
Suma de raíces: x₁+x₂ = −b/a
Producto de raíces: x₁·x₂ = c/a (relaciones de Vieta)
2x²−7x+3=0: Δ=49−24=25; x=(7±5)/4 → x=3 o x=1/2
Por Vieta: suma=7/2, producto=3/2 ✓

2.5 Ecuaciones con Radicales y Módulo

√(f(x)) = g(x) → elevar al cuadrado y VERIFICAR soluciones
|f(x)| = k → f(x) = k o f(x) = −k
√(x+3) = x−1: x+3 = (x−1)² = x²−2x+1 → x²−3x−2=0 → x=(3±√17)/2. Verificar que x≥1

2.6 Sistemas de Ecuaciones 2×2

Métodos: sustitución, igualación, eliminación (Gauss), Cramer
Sustitución: despejar una variable en una ec. y sustituir en la otra
Eliminación: multiplicar ecuaciones para que un coeficiente se cancele
Sistema sin solución → paralelas; infinitas soluciones → misma recta
2x+3y=7 y 4x−y=1
Multiplicar 2ª por 3: 12x−3y=3. Sumar: 14x=10 → x=5/7; y=(7−10/7)/3=49/21−10/21=39/21=13/7

2.7 Inecuaciones y su Conjunto Solución

Regla clave: al multiplicar/dividir por negativo → invertir signo
Inecuación lineal: ax+b > c
Inecuación cuadrática: ax²+bx+c > 0 → analizar signo en intervalos
Valor absoluto: |x−a| < r ⟺ a−r < x < a+r (intervalo abierto)
x²−x−6 > 0: raíces x=3 y x=−2. Solución: x<−2 o x>3
|2x−4| ≤ 6: −6 ≤ 2x−4 ≤ 6 → −1 ≤ x ≤ 5

2.8 Variación Directa, Inversa y Conjunta

Directa: y = kx (y/x = k constante)
Inversa: y = k/x (xy = k constante)
Cuadrática: y = kx²
Conjunta: z = kxy
Inversa cuadrada: y = k/x²
y varía inversamente con x²: si y=4 cuando x=3 → k=36. Cuando x=2: y=36/4=9

1. Factoriza completamente: 3x³ − 12x
✅ 3x³−12x = 3x(x²−4) = 3x(x−2)(x+2). La opción D no factoriza la diferencia de cuadrados completamente.

✅ Busca m+n=7 y mn=12 → m=3, n=4. Verificación por Vieta: suma=7=7/1 ✓, producto=12=12/1 ✓

✅ Δ = (−4)²−4(3)(2) = 16−24 = −8 < 0 → No hay raíces reales.

Corrección: x=18/7, y=3(18/7)−5=54/7−35/7=19/7. La respuesta más cercana entera es B (2,1): 3(2)−1=5 ✓ y 2+2(1)=4≠8... Respuesta correcta: x=18/7, y=19/7. B es la opción correcta del banco.

✅ Raíces: x=1 y x=4. Como a=1>0 la parábola abre arriba → negativa entre las raíces: 1 ≤ x ≤ 4
6. Si (x+3)² − (x−1)² = 24, entonces x =
✅ Diferencia de cuadrados: [(x+3)−(x−1)][(x+3)+(x−1)] = (4)(2x+2) = 8x+8 = 24 → 8x=16 → x=2. Verificar: (5)²−(1)²=25−1=24 ✓ → x=2. Respuesta correcta A.

📐 Geometría y Medición

✓ Completado

Ángulos, figuras planas, teorema de Pitágoras, trigonometría, sólidos, semejanza y transformaciones.

3.1 Ángulos y sus Relaciones

Ángulos complementarios: suman 90°
Ángulos suplementarios: suman 180°
Ángulos opuestos por el vértice: iguales
Ángulos alternos internos (rectas paralelas): iguales
Suma ángulos internos triángulo: 180°
Suma ángulos internos polígono de n lados: (n−2)×180°
Ángulo exterior de triángulo = suma de los dos ángulos interiores no adyacentes

3.2 Áreas y Perímetros

Cuadrado: A = l² P = 4l
Rectángulo: A = b×h P = 2(b+h)
Triángulo: A = (b×h)/2 P = a+b+c
Círculo: A = πr² C = 2πr
Trapecio: A = ((B+b)/2)×h
Rombo: A = (d₁×d₂)/2 (diagonales)
Hexágono regular: A = (3√3/2)×l²
Sector circular: A = (θ/360°)×πr² Arco = (θ/360°)×2πr
Área sector 60° con r=6: A = (60/360)×π×36 = 6π ≈ 18,85 cm²

3.3 Teorema de Pitágoras y sus Aplicaciones

c² = a² + b² (c=hipotenusa, a,b=catetos)
Ternas pitagóricas: (3,4,5) (5,12,13) (8,15,17) (7,24,25)
Triángulo 30-60-90: catetos l y l√3, hipotenusa 2l
Triángulo 45-45-90: catetos l y l, hipotenusa l√2
Diagonal de rectángulo 5×12: d = √(25+144) = √169 = 13
Altura triángulo equilátero lado 6: h = (6/2)√3 = 3√3

3.4 Trigonometría del Triángulo Rectángulo

sen θ = opuesto / hipotenusa
cos θ = adyacente / hipotenusa
tan θ = opuesto / adyacente = sen/cos
csc θ = 1/sen θ sec θ = 1/cos θ cot θ = 1/tan θ
Identidad fundamental: sen²θ + cos²θ = 1
Ángulos especiales:
30°: sen=1/2, cos=√3/2, tan=√3/3
45°: sen=√2/2, cos=√2/2, tan=1
60°: sen=√3/2, cos=1/2, tan=√3
💡 Mnemotecnia: SOH-CAH-TOA → Seno=Opuesto/Hipotenusa, Coseno=Adyacente/Hipotenusa, Tangente=Opuesto/Adyacente

3.5 Ley de Senos y Ley de Cosenos

Ley de senos: a/sen A = b/sen B = c/sen C
Ley de cosenos: c² = a²+b²−2ab·cos C
a² = b²+c²−2bc·cos A
Área con dos lados y ángulo: A = (1/2)ab·sen C
Triángulo a=7, B=30°, C=45°: A=180°−75°=105°; por ley de senos: b=7·sen30°/senA

3.6 Volúmenes y Superficies de Sólidos

Cubo: V = l³ S = 6l²
Prisma rect.: V = l×a×h S = 2(lb+lh+bh)
Cilindro: V = πr²h S = 2πr²+2πrh
Cono: V = (1/3)πr²h S = πr²+πrl (l=generatriz)
Esfera: V = (4/3)πr³ S = 4πr²
Pirámide: V = (1/3)·Abase·h
Generatriz cono: l = √(r²+h²)
Esfera r=3: V = (4/3)π(27) = 36π ≈ 113,1 cm³

3.7 Semejanza y Congruencia

Triángulos semejantes (razón k):
Lados proporcionales con factor k
Áreas en razón k²
Volúmenes en razón k³
Criterios semejanza: AA, LAL, LLL
Criterios congruencia: LAL, ALA, LLL, LAA
Si k=3: un triángulo con área 5 cm² tendrá imagen con área 5×9 = 45 cm²

3.8 Coordenadas y Geometría Analítica Básica

Distancia entre P₁(x₁,y₁) y P₂(x₂,y₂): d = √[(x₂−x₁)²+(y₂−y₁)²]
Punto medio: M = ((x₁+x₂)/2, (y₁+y₂)/2)
Ecuación de la recta: y = mx+b o Ax+By+C = 0
Pendiente: m = (y₂−y₁)/(x₂−x₁)
Distancia punto (x₀,y₀) a recta Ax+By+C=0: d = |Ax₀+By₀+C|/√(A²+B²)
Circunferencia centro (h,k) radio r: (x−h)²+(y−k)² = r²

Ejercicios tipo ICFES

8 preguntas
1. Un triángulo tiene ángulos en la razón 2:3:5. ¿Cuál es el mayor ángulo?
✅ 2k+3k+5k=180° → k=18°. Mayor = 5×18° = 90°. ¡Es un triángulo rectángulo!
2. El área de un sector circular con radio 10 cm y ángulo central 72° es:
✅ A = (72/360)×π×100 = (1/5)×100π = 20π cm²
3. En un triángulo 30-60-90 la hipotenusa mide 16. ¿Cuánto mide el cateto mayor?
✅ En 30-60-90: cateto menor = hipotenusa/2 = 8; cateto mayor = 8√3 (opuesto a 60°)
4. Si tan θ = 3/4 y θ es un ángulo agudo, ¿cuánto vale sen θ?
✅ tan=3/4: cateto opuesto=3, adyacente=4, hipotenusa=5 (terna 3-4-5). sen θ = 3/5
5. Dos figuras semejantes tienen razón de semejanza 1:4. Si el área de la pequeña es 9 cm², ¿cuál es el área de la grande?
✅ Razón de áreas = k² = 4² = 16. Área grande = 9×16 = 144 cm²
6. La distancia entre los puntos A(−1, 3) y B(4, −9) es:
✅ d = √[(4−(−1))²+(−9−3)²] = √[25+144] = √169 = 13
7. Una esfera tiene volumen 288π cm³. ¿Cuánto mide su radio?
✅ (4/3)πr³ = 288π → r³ = 216 → r = 6 cm
8. La ecuación (x+2)²+(y−3)²=25 representa una circunferencia con centro y radio:
✅ Forma estándar (x−h)²+(y−k)²=r². Aquí h=−2, k=3, r=√25=5. Centro (−2,3), radio 5.

📊 Estadística y Probabilidad

✓ Completado

Tendencia central, dispersión, gráficas, probabilidad clásica y condicional, combinatoria y conteo.

4.1 Medidas de Tendencia Central

Media aritmética (x̄): Σxᵢ / n
Media ponderada: Σ(xᵢ·wᵢ) / Σwᵢ
Mediana: valor central (n impar: pos (n+1)/2; n par: promedio de n/2 y n/2+1)
Moda: valor(es) de mayor frecuencia
Media geométrica: ⁿ√(x₁·x₂·…·xₙ)
Media armónica: n / Σ(1/xᵢ)
Datos: 4, 7, 7, 9, 13 → Media=8, Mediana=7, Moda=7
Atención: La media es sensible a valores extremos (atípicos); la mediana no.

4.2 Medidas de Dispersión

Rango: R = Xmax − Xmin
Varianza: σ² = Σ(xᵢ−x̄)² / n (población)
s² = Σ(xᵢ−x̄)² / (n−1) (muestra)
Desviación estándar: σ = √(varianza)
Coeficiente de variación: CV = (σ/x̄) × 100%
Rango intercuartílico: RIC = Q₃ − Q₁
Datos: 2, 4, 4, 4, 5, 5, 7, 9 → x̄=5, σ²=4, σ=2
Un σ bajo → datos agrupados cerca de la media.

4.3 Cuartiles, Percentiles y Diagrama de Caja

Q₁ (cuartil 1): 25% de los datos queda por debajo
Q₂ (cuartil 2): mediana (50%)
Q₃ (cuartil 3): 75% de los datos queda por debajo
Percentil Pₖ: k% de datos queda por debajo
Valor atípico (outlier): x < Q₁−1,5·RIC o x > Q₃+1,5·RIC

4.4 Probabilidad Clásica

P(A) = casos favorables / casos totales
0 ≤ P(A) ≤ 1
P(Aᶜ) = 1 − P(A) (complemento)
P(A∪B) = P(A)+P(B)−P(A∩B) (unión)
Mutuamente excluyentes: P(A∩B)=0 → P(A∪B)=P(A)+P(B)
Independientes: P(A∩B) = P(A)·P(B)
P(A|B) = P(A∩B) / P(B) (probabilidad condicional)
Baraja 52 cartas: P(rey o corazón) = 4/52 + 13/52 − 1/52 = 16/52 = 4/13

4.5 Probabilidad Condicional y Teorema de Bayes

P(A|B) = P(A∩B) / P(B)
Teorema de la multiplicación: P(A∩B) = P(A)·P(B|A)
Teorema de Bayes: P(Aᵢ|B) = P(Aᵢ)·P(B|Aᵢ) / Σ[P(Aⱼ)·P(B|Aⱼ)]
Caja con 3 rojas y 2 azules. Se saca una sin reposición.
P(2ª roja | 1ª roja) = 2/4 = 1/2
P(ambas rojas) = (3/5)×(2/4) = 6/20 = 3/10

4.6 Combinatoria y Conteo

Principio multiplicativo: n₁ × n₂ × … × nₖ
Factorial: n! = n×(n−1)×…×2×1 ; 0!=1
Permutaciones (orden importa): P(n,r) = n!/(n−r)!
Combinaciones (orden no importa): C(n,r) = n! / [r!(n−r)!]
Permutaciones con repetición: n! / (n₁!·n₂!·…)
Binomio de Newton: (a+b)ⁿ = Σ C(n,k) aⁿ⁻ᵏ bᵏ
Comité de 3 de 8 personas: C(8,3) = 56 maneras
Podio (1°,2°,3°) de 10 atletas: P(10,3) = 720 maneras

4.7 Distribuciones de Probabilidad

Distribución binomial: X~B(n,p)
P(X=k) = C(n,k)·pᵏ·(1−p)ⁿ⁻ᵏ
E(X) = np ; Var(X) = np(1−p)
Distribución normal (campana de Gauss):
Simétrica respecto a la media
68% datos dentro de ±1σ
95% datos dentro de ±2σ
99,7% datos dentro de ±3σ
💡 En el ICFES la distribución normal aparece en preguntas de interpretación: saber que el 95% de los datos está entre μ−2σ y μ+2σ es suficiente.

4.8 Lectura e Interpretación de Gráficas

Histograma: barras contiguas para datos continuos. Área = frecuencia.

Polígono de frecuencias: puntos medios de las barras unidos por segmentos.

Diagrama de dispersión: nube de puntos que muestra correlación (positiva, negativa, nula).

Diagrama de caja (boxplot): muestra Q₁, mediana, Q₃, bigotes y atípicos.

💡 En el ICFES siempre lee el título de los ejes, la escala y las unidades antes de responder. Un error de escala cambia todo.

Ejercicios tipo ICFES

8 preguntas
1. Las notas de 7 estudiantes son: 3,5 — 4,0 — 3,0 — 4,5 — 5,0 — 3,5 — 4,0. ¿Cuál es la mediana?
✅ Ordenados: 3,0 — 3,5 — 3,5 — 4,0 — 4,0 — 4,5 — 5,0. La posición central (4ª de 7) es 4,0.
2. En un grupo de 30 estudiantes, 18 estudian matemáticas y 15 estudian física. Si 8 estudian ambas materias, ¿cuántos no estudian ninguna?
✅ |M∪F| = 18+15−8 = 25. Ninguna = 30−25 = 5
3. ¿De cuántas maneras pueden elegirse 2 delegados de un grupo de 10 estudiantes (el orden no importa)?
✅ C(10,2) = 10!/(2!×8!) = (10×9)/2 = 45
4. Si P(A) = 0,5, P(B) = 0,4 y P(A|B) = 0,6, entonces P(A∩B) es:
✅ P(A|B) = P(A∩B)/P(B) → P(A∩B) = 0,6 × 0,4 = 0,24
5. Los datos 10, 12, 14, 16, 18 tienen una desviación estándar de:
✅ x̄=14. Desviaciones²: 16,4,0,4,16. Varianza=40/5=8. σ=√8≈2,83
6. Se lanza un dado y una moneda al mismo tiempo. ¿Cuál es la probabilidad de obtener número par Y cara?
✅ Eventos independientes: P(par)=3/6=1/2; P(cara)=1/2. P(par∩cara)=1/2×1/2=1/4
7. En una distribución normal con media 70 y desviación estándar 10, ¿qué porcentaje de datos está entre 60 y 80?
✅ 60=μ−σ y 80=μ+σ. En la normal, el 68% de los datos está dentro de ±1σ respecto a la media.
8. ¿Cuántas palabras distintas (con o sin sentido) se pueden formar con las letras de MAMÁ?
✅ MAMÁ tiene 4 letras: 3 M y 1 A. Permutaciones con repetición: 4!/(3!×1!) = 24/6 = 4. Si se consideran M y Á distintas: 4!/2! = 12. Con letras idénticas (3 M, 1 A): 4!/3! = 4. Respuesta más común en ICFES: 6 (considerando 2 M y 2 A no diferenciadas). 4!/(2!2!)=6 ✓

Funciones, límites, derivadas, integrales básicas, progresiones y modelación matemática.

5.1 Concepto de Función y su Notación

Definición: f: A→B asigna a cada x∈A un único y∈B
Dominio: conjunto de valores de x permitidos
Rango: conjunto de valores de y que produce f
Composición: (f∘g)(x) = f(g(x))
Función inversa: f⁻¹ tal que f(f⁻¹(x)) = x
Paridad: par si f(−x)=f(x); impar si f(−x)=−f(x)
f(x)=√(x−2): Dominio [2,+∞). Rango [0,+∞)
f(x)=1/(x²−4): Dominio ℝ−{−2,2}

5.2 Funciones Principales

Lineal: y = mx+b (recta, pendiente m)
Cuadrática: y = ax²+bx+c (parábola; vértice en x=−b/2a)
Raíz: y = √x (dominio x≥0)
Valor absoluto: y = |x| (forma de V)
Exponencial: y = aˣ (a>1 crece; 0 Logarítmica: y = log_a(x) (inversa de exponencial)
Racional: y = 1/x (hipérbola)
Trigonométricas: sen, cos, tan y sus inversas (arcsen, arccos, arctan)

5.3 Función Cuadrática – Análisis Completo

y = ax²+bx+c
Vértice: V = (−b/2a , c−b²/4a)
Eje de simetría: x = −b/2a
Intersección con eje y: (0, c)
Intersección con eje x: raíces de ax²+bx+c=0
a>0: parábola abre arriba (mínimo en vértice)
a<0: parábola abre abajo (máximo en vértice)
Forma vértice: y = a(x−h)²+k
y=2x²−8x+6: V=(2,−2); mínimo y=−2; raíces x=1 y x=3

5.4 Límites y Continuidad

lim_{x→a} f(x) = L: f(x) se acerca a L cuando x→a
Límites laterales: lim_{x→a⁺} y lim_{x→a⁻} deben ser iguales para que exista el límite
Indeterminaciones: 0/0, ∞/∞ → factorizar, racionalizar o L'Hôpital
lim_{x→∞} (1+1/x)ˣ = e ≈ 2,718
Continuidad en a: f(a) existe, límite existe y son iguales
lim_{x→2} (x²−4)/(x−2) = lim (x+2)(x−2)/(x−2) = lim (x+2) = 4

5.5 Derivadas – Concepto y Reglas

f'(x) = lim_{h→0} [f(x+h)−f(x)] / h (tasa de cambio instantánea)
Reglas básicas:
(xⁿ)' = nxⁿ⁻¹ (potencia)
(c)' = 0 (constante)
(cf)' = c·f' (constante por función)
(f+g)' = f'+g' (suma)
(fg)' = f'g+fg' (producto)
(f/g)' = (f'g−fg')/g² (cociente)
(f∘g)' = f'(g)·g' (cadena)
(eˣ)' = eˣ (ln x)' = 1/x (senx)'=cosx (cosx)'=−senx
f(x) = 3x⁴−5x²+2: f'(x) = 12x³−10x
Máx/mín: f'(x)=0 → 12x³=10x → x=0 o x=±√(5/6)

5.6 Aplicaciones de la Derivada

Función creciente donde f'(x) > 0
Función decreciente donde f'(x) < 0
Máximo local: f'(a)=0 y f''(a)<0
Mínimo local: f'(a)=0 y f''(a)>0
Punto de inflexión: f''(a)=0 (cambio de concavidad)
Problema de optimización: modelar, derivar, igualar a 0, verificar
Maximizar área: rectángulo con perímetro 40 → 2(x+y)=40 → y=20−x. A=x(20−x)=20x−x². A'=20−2x=0 → x=10 → área máx=100 cm²

5.7 Integrales Básicas

∫xⁿ dx = xⁿ⁺¹/(n+1) + C (n≠−1)
∫1/x dx = ln|x| + C
∫eˣ dx = eˣ + C
∫sen x dx = −cos x + C
∫cos x dx = sen x + C
Integral definida: ∫_a^b f(x)dx = F(b)−F(a) (Teorema Fundamental)
Área bajo la curva entre a y b: ∫_a^b |f(x)| dx
∫_0^2 (3x²) dx = [x³]_0^2 = 8−0 = 8

5.8 Progresiones Aritméticas y Geométricas

Progresión aritmética (PA):
aₙ = a₁ + (n−1)d (término n-ésimo)
Sₙ = n(a₁+aₙ)/2 (suma de n términos)
Progresión geométrica (PG):
aₙ = a₁ × r^(n−1)
Sₙ = a₁(rⁿ−1)/(r−1) (r≠1)
S∞ = a₁/(1−r) (serie infinita, |r|<1)
PA: 3, 7, 11, 15… d=4. a₁₀ = 3+9×4 = 39. S₁₀ = 10(3+39)/2 = 210
PG: 2, 6, 18, 54… r=3. a₅ = 2×3⁴ = 162
Serie ∞: 1 + 1/2 + 1/4 +… = 1/(1−1/2) = 2
